Ferramentas Utilizadas

Fonte

  • Nome: Komika Axis
  • Origem: DaFont.com
  • Estilo: Fonte estilo quadrinhos/cartoon

Softwares

  • Pixilart: Criação dos personagens em estilo pixelado

  • Visual Studio Code: Editor de código utilizado no desenvolvimento do projeto

Considerações

Neste projeto, nós, educandos do Instituto Cacau Show, criamos um jogo curto e divertido para entreter os clientes enquanto aguardam seus pedidos. A ideia é tornar o tempo de espera mais agradável e proporcionar uma experiência diferente aos clientes.

Durante o desenvolvimento, aprendemos a trabalhar em grupo, compartilhar ideias e buscar soluções em conjunto. Esse projeto contribuiu para nosso aprendizado e para o desenvolvimento de habilidades importantes para o futuro.
